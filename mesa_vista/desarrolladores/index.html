Mesa de Partes Virtual

Aplicación Angular para la presentación y registro de documentos administrativos.

Framework: Angular 20  |  UI: PrimeNG 20 (Aura)  |  CSS: Tailwind CSS 4  |  SSR: Express (producción)  |  Tipo: Standalone Components

Stack Tecnológico

Angular 20

Standalone components. Sin NgModules. Application builder.

PrimeNG 20

Stepper, Dialog, Select, Toast, Button, Card, InputText, Message.

Tailwind CSS 4

PostCSS plugin. Config en src/assets/tailwind.css.

HttpClient Fetch

Con interceptores funcionales para autenticación Bearer.

Express (producción)

Servidor Node.js que sirve el build en puerto 4200.

TypeScript 5.8

Modo estricto. Path alias @/* → src/app/*.

Karma + Jasmine

Testing unitario. npm test para ejecutar.

PrimeIcons 7

Iconos utilizados en botones, menús y estados.

Arquitectura

Diagrama de herencia de componentes

BaseMesaPartesComponent
├── Personanatural
└── Personanajuridica

DocumentosStepComponent (reutilizado en pasos 2 y 3)
Mesapartes (independiente)

Patrones

  • Base Class / Template Method: BaseMesaPartesComponent define la lógica compartida; las subclases implementan initDocumentosIdentidad() y sus propios finalizar().
  • Two-way binding personalizado: DocumentosStepComponent expone inputs con eventos Change para banana-in-a-box.
  • Functional Interceptor: HttpInterceptorFn para inyección de token JWT.
  • Standalone Components: Sin NgModules, cada componente declara sus propios imports.

Flujo de Registro

Inicio → Acepta términos [Sí] →
Persona Natural → Paso 1: RENIEC → Paso 2: Documentos → Paso 3: Final
Persona Jurídica → Paso 1: SUNAT → Paso 2: Documentos → Paso 3: Final

POST /api/public/expediente
[Éxito] → Diálogo "Registro Exitoso" → OK → Inicio
[Error] → Toast de error

2DocumentosStepComponent (modo documentos)Tipo doc., asunto, PDF, anexos
3DocumentosStepComponent (modo final)Resumen + botón Finalizar

Servicio API

Servicio singleton (providedIn: 'root') en apiService.ts. URL base hardcodeada:

private apiUrl = 'http://sgd.emapat.com.pe:9000';
// Alternativa: 'http://localhost:9000'

Endpoints

MétodoEndpointAuthDescripción
GET {apiUrl}/reniec/buscar?dni={dni} Public Busca persona natural por DNI
GET {apiUrl}/api/public/buscar?ruc={ruc} Public Busca persona jurídica por RUC
GET {apiUrl}/api/public/listaTipoDocumento Public Catálogo de tipos de documento
GET {apiUrl}/reniec/listar?q={texto} Public Busca ubigeo (mín. 2 caracteres)
POST {apiUrl}/api/public/expediente Public Envía expediente (multipart/form-data)

postExpediente — Detalle del multipart

Campo FormDataValor

Interceptor HTTP

Interceptor funcional (HttpInterceptorFn) en mesapartes-interceptor.ts. Inyecta token Bearer en todas las peticiones excepto en endpoints públicos.

const token = 'sk_7825.jyG4d88J0cttJU8q2gxstx1y2kqgc29E';

Endpoints públicos (sin token)

  • URLs que contengan /reniec
  • URLs que contengan /api/auth/login
  • URLs que contengan /api/auth/register
  • URLs que contengan api/public/

Registro

// app.config.ts
provideHttpClient(withFetch(), withInterceptors([mesapartesInterceptor]))

Setup Local

Requisitos

  • Node.js 20+
  • npm 10+
  • Angular CLI 20 (npm install -g @angular/cli)

Pasos

git clone <repo-url>
cd mesa_vista
npm install
npm start                     # ng serve → http://localhost:4200

Testing

npm test                      # ng test (Karma + Jasmine)

Formato de código

npm run format                # Prettier

Despliegue

Build de producción

npm run build                 # → dist/sakai-ng/browser/

Vercel

El proyecto incluye vercel.json con rewrites SPA:

{
  "rewrites": [
    { "source": "/:path*", "destination": "/index.html" }
  ],
  "trailingSlash": false
}

Servidor Express

Archivo serverMesaPartesVista.js.js disponible en la raíz. Sirve el build en puerto 4200:

node src/serverMesaPartesVista.js.js
# Angular servido en http://0.0.0.0:4200

Variables de entorno

No existen archivos environment.ts. La URL de la API y el token están hardcodeados:

  • apiService.ts: private apiUrl = 'http://sgd.emapat.com.pe:9000'
  • mesapartes-interceptor.ts: const token = 'sk_7825.jyG4d88J0cttJU8q2gxstx1y2kqgc29E'
