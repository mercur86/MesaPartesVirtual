Manual de Despliegue

Procedimiento para desplegar el backend y frontend de la Mesa de Partes Virtual en el servidor de producción.

Servidor: Linux (ruta base /home/sgd-admin/)  |  Java: 17  |  Node: 20+  |  PM2: Gestor de procesos

Backend Despliegue del Backend

Pasos para generar y ejecutar el JAR del backend Spring Boot en el servidor.

1. Generar el JAR

Abre el proyecto backend en IntelliJ IDEA Community Edition y en la terminal integrada ejecuta:

mvn clean install -DskipTests

Esto generará el archivo mesapartes-0.0.1-SNAPSHOT.jar en la carpeta target/.

Recomendación: Usa IntelliJ IDEA Community Edition para abrir el proyecto Maven, ya que integra automáticamente las dependencias, el SDK de Java 17 y la terminal para ejecutar Maven sin configuración adicional.

2. Subir el JAR al servidor

Usa una herramienta SMTP, FTP o SCP para transferir el archivo JAR al servidor.

Ruta destino:

/home/sgd-admin/

3. Ejecutar el JAR

Conéctate al servidor vía SSH y ejecuta:

/opt/java17/bin/java -jar "/home/sgd-admin/mesapartes-0.0.1-SNAPSHOT.jar" > /home/sgd-admin/logs/mesapartes.log 2>&1 &

El comando:

  • Usa Java 17 desde /opt/java17/bin/java
  • Ejecuta el JAR en segundo plano (&)
  • Redirige la salida estándar y de errores al archivo de log

4. Verificar el Log

Para monitorear la salida del backend en tiempo real:

tail -f /home/sgd-admin/logs/mesapartes.log

Presiona Ctrl + C para salir del modo seguimiento.

Frontend Despliegue del Frontend

Pasos para construir y servir la aplicación Angular en el servidor usando PM2.

1. Verificar el estado de PM2

Revisa si el proyecto ya está corriendo con PM2:

pm2 list
Si aparece serverMesaPartesVista en la lista: el proyecto ya está corriendo. No es necesario continuar.
Si no aparece nada: continúa con los siguientes pasos.

2. Entrar al directorio y hacer build

cd /home/sgd-admin/mesaViertual/MesaPartesVirtual/mesa_vista
npm run build

Esto genera la carpeta dist/sakai-ng/browser/ con los archivos estáticos optimizados para producción.

3. Iniciar el servidor con PM2

pm2 start serverMesaPartesVista.js

PM2 mantendrá la aplicación corriendo de forma permanente y la reiniciará automáticamente si falla.

Nota: El archivo serverMesaPartesVista.js es un servidor Express que sirve el build de Angular en el puerto 4200 y redirige todas las rutas al index.html (SPA).
